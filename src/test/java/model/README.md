# Test del `model`

Contiene i test delle principali **Entity** del progetto.

## File

- `ClienteTest.java`: controlla dati cliente e patente.
- `BarcaTest.java`: controlla le caratteristiche comuni delle barche.
- `BarcaMotoreTest.java`: test specifici delle barche a motore.
- `BarcaVelaTest.java`: test specifici delle barche a vela.
- `SedeTest.java`: controlla la classe Sede.
- `PrenotazioneTest.java`: verifica prenotazioni, stati e regole del Model.
- `NoleggioTest.java`: verifica il ciclo di vita del noleggio.
- `ManutenzioneTest.java`: verifica il ciclo di vita della manutenzione.
- `ModelTestFactory.java`: crea oggetti di supporto riutilizzati nei test.

# Cartella `src/test/java`

Contiene tutte le classi usate per i **test JUnit**.

- `model/`: test delle Entity e delle transizioni di stato.
- `controller/`: test del Controller e delle business rule.
- `dao/`: test dei contratti DAO.
- `dao/impl/`: test di integrazione con i file CSV.
- `exception/`: test delle eccezioni del dominio.

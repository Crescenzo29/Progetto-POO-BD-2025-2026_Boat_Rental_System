# Test del `controller`

Contiene i test dedicati al **NoleggioBarcheController** e alle principali regole applicative.

## File

- `NoleggioBarcheControllerTest.java`: controlla struttura e operazioni principali del Controller.
- `NoleggioBarcheBusinessRulesTest.java`: verifica le principali regole di business.
- `NoleggioBarcheGuiControllerTest.java`: verifica il collegamento tra funzionalità GUI e Controller.
- `ManutenzioneIndisponibileCsvTest.java`: controlla la gestione di `indisponibileFinoAl` durante una manutenzione.
- `ManutenzionePrioritaPrenotazioneTest.java`: verifica la priorità della manutenzione sulle prenotazioni confermate e i casi di blocco.

# Cartella `src/main/java`

Questa cartella contiene tutte le **classi Java principali** del progetto.

- `Main.java`: punto di ingresso dell'applicazione; prepara i DAO, il Controller e avvia la GUI.
- `controller/`: logica applicativa e regole di business.
- `dao/`: interfacce per l'accesso ai dati.
- `dao/impl/`: implementazioni DAO che lavorano sui CSV.
- `exception/`: eccezioni personalizzate.
- `gui/`: interfaccia grafica Swing.
- `model/`: classi che rappresentano il dominio del noleggio barche.

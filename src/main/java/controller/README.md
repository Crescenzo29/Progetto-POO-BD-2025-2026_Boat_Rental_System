# Package `controller`

Contiene il **Controller principale** dell'applicazione.

## File

- `NoleggioBarcheController.java`: collega GUI, Model e DAO e gestisce le principali operazioni su clienti, barche, prenotazioni, noleggi e manutenzioni.
- `package-info.java`: breve descrizione del package.

Qui sono controllate anche le principali **regole di business** che coinvolgono più oggetti.
